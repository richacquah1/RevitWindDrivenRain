# RevitWindDrivenRain

RevitWindDrivenRain is an Autodesk Revit add-in for geometry-resolved wind-driven rain (WDR) exposure assessment on building façades, within a workflow informed by ISO 15927-3.

## Source code

The complete C# and WPF/XAML source code is maintained directly in the root of this repository. The main Visual Studio files are available here:

- [Visual Studio solution](RevitWindDrivenRain.sln)
- [Visual Studio project](RevitWindDrivenRain.csproj)
- [WDR command implementation](Command_WDR/)
- [Ray-casting implementation](Command_Ray%20Casting/)
- [Simulation commands](Command_Simulations/)
- [Forms and user interface](Forms/)
- [Utilities](Utilities/)
- [Resources](Resources/)

Browse the folders and individual source files directly on GitHub, or clone the repository to inspect and build the project.

## Software archive

The original packaged software archive is retained as [RevitWindDrivenRain.zip](RevitWindDrivenRain.zip). The source files in this repository provide the browsable project implementation.
